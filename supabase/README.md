# Banco UMC

Execute a migration em ordem no SQL Editor do Supabase. A migration usa RLS e deixa consultas somente para usuários autenticados. A política inicial permite inserir vendas a administradores/gerentes; a ação de venda ficará exposta por uma rota autenticada no ciclo de integração. Não coloque `service_role` no cliente.

Dados de outubro configurados: Qualificatória R$ 2.500.000; Main Event R$ 3.500.000; Unificação R$ 5.000.000. Confira premiações dos Eventos 2 e 3 com a diretoria e ajuste `reward_rules`/`events` antes do uso.
